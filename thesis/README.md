# Short thesis

The PDF integrates the five-size batch-versus-streaming study and the later
[baseline controls](../experiments/baseline-gates/README.md). It explains why
shared residency changes the recommendation where the feature table fits.
The three research questions match the [contribution plan](../docs/CONTRIBUTION_PLAN.md);
the text distinguishes completed evidence from the proposed predictor and selector.

Start with [short-thesis.pdf](short-thesis.pdf), or read the same text in
[short-thesis.md](short-thesis.md). The structure follows the problem,
prior work and three research questions, the prepared-batch idea, controlled
experiments, preparation costs, practical implications and conclusion.

All workload-size curves contain five actual size points for each input
family. Plan-lifetime curves contain five analytically evaluated reuse counts.
They are labelled separately from measured CPU times and simulated DPU cycles.
The underlying [five-point artifact](../experiments/access-plan-fivepoint/README.md)
retains 180 configurations (108 reused, 72 new) and 1,320 CPU timings.
The baseline screen adds 14 executions and reuses 24 comparators from that grid.
Its results appear as a table because it tests one size, not a five-point curve.

This is a concise account of the current bounded study, not a claim that
hardware acceleration or the broader adaptive-prefetching objective has been
validated. The earlier artifacts remain available separately.

## Build

From the repository root, install the pinned document dependencies into an
isolated environment, or the ignored local dependency directory:

```sh
python3 -m pip install --target .deps/thesis-pdf -r thesis/requirements.txt
PYTHONPATH=.deps/thesis-pdf python3 scripts/thesis_figures.py
python3 scripts/build_short_thesis.py
pdfinfo thesis/short-thesis.pdf
```

The build uses Liberation Serif, Liberation Mono and GNU FreeSans font files
from `/usr/share/fonts`, plus `pdfinfo` from Poppler. The current source is
Markdown; ReportLab produces the PDF with embedded fonts and numbered
references. The cycle table is refreshed from the retained CSV data during
the build. Figure PNGs and standalone vector PDFs are generated by the figure
script. Every plotted series and its five x values are retained in
[figures/plotted-data.json](figures/plotted-data.json).

[build.json](build.json) records the actual PDF page count, dependency versions
and source/PDF/figure/evidence hashes. It is the authoritative page-count
record; rebuilding does not require manually synchronizing a second count.
PDF and standalone figure metadata use fixed timestamps for reproducible builds;
the research date appears on the first page and in the footer.
The PDF includes no fabricated supervisor or university information.
The [validation record](../docs/VALIDATION.md) links the document checks to
the corresponding experiment artifacts.

## Verify the evidence

```sh
python3 scripts/access_plan_fivepoint.py verify
python3 scripts/access_plan_fivepoint.py replay
python3 scripts/access_plan_gates.py verify
python3 scripts/access_plan_gates.py replay
```

Frozen replay needs the pinned simulator; see the experiment README for setup.
Rerunning CPU measurements can change preparation and break-even estimates.
Keep those new timings separate from the retained campaign used by this text.
