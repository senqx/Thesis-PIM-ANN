# Five-point extension for the short thesis

Specified before the additional simulations, 23 November 2026. The preceding
three-size study remains unchanged. Add 384 and 1,536 destinations to give
192, 384, 768, 1,536 and 3,072 destinations for every input family and policy.
Keep community, uniform and sampled ca-GrQc, seeds 23/61, twelve tasklets,
8-byte integer features, three batch windows and three streaming buffers.

Reuse all six exact linked programs and the 108 existing DPU records. Run
72 additional configurations at the two new sizes: 180 configurations in the
combined grid. The 108 reused records are not new experiments. Do not tune the
candidate or select a different workload after inspecting the new points.

Measure preparation again for all five sizes in one new host timing campaign,
with one warm-up and 11 shuffled-order samples for the four distinct encoders.
This gives 1,320 timings. The three streaming buffer variants still share one
identical host encoding. Keep the old timing campaign unchanged, and use only
the new campaign for the short thesis's preparation and amortization figures.

Use the same independent output, metadata, exact byte-count and capacity
checks. Retain every new frozen program input/output, counter and model option.
Compare with the fastest of the three eligible streaming buffers per input.
Five workload sizes improve visibility of the trend; they do not establish
five independent real datasets, statistical significance or hardware fidelity.

Every workload-size curve in the short thesis will contain five actual size
points per input family. Plan-lifetime curves use five explicitly modelled
reuse counts (1, 10, 100, 1,000, 10,000). Never turn a nonexistent break-even
threshold into a finite plot point. Mark measured CPU timings, simulated DPU
cycles and analytically modelled reuse costs as different kinds of evidence.
